# 요약 파일 템플릿 (DESIGN.md A안: 줄별 근거형)

아래 두 형식 중 상황에 맞는 하나를 `output/<날짜>/summary-NN.md`로 쓴다. 이 안내 문단과 코드 펜스는 쓰지 않는다.

## 성공 형식 (원문 확인됨)

```
# <제목>
- 상태: ✅ 원문 확인
- 데이터: 실보도
- 언론사: <언론사>
- 발행일: <YYYY-MM-DD HH:MM KST>
- URL: <URL>
- 확인 시각: <YYYY-MM-DD HH:MM KST>
- 원문 저장: source-NN.txt

## 3줄 요약
1. <요약 1>
   > 근거: "<원문에서 그대로 복사한 문장>"
2. <요약 2>
   > 근거: "<원문에서 그대로 복사한 문장>"
3. <요약 3>
   > 근거: "<원문에서 그대로 복사한 문장>"
```

가상 기사(samples/)일 때:
- 제목 줄: `# [가상 예시] <제목>`
- `- 데이터: 가상 예시`
- `- URL:` 에는 samples 파일 경로

## 실패 형식 (접근 실패)

```
# 접근 실패: <URL>
- 상태: ❌ 접근 실패 (사유: <예: 404 / 로그인 필요 / 본문 200자 미만 / 아름다운가게 관련 없음>)
- 데이터: 실보도
- URL: <URL>
- 확인 시각: <YYYY-MM-DD HH:MM KST>

요약을 만들지 않았습니다.
```

실패 파일에는 `## 3줄 요약` 섹션을 만들지 않고 source 파일도 저장하지 않는다.

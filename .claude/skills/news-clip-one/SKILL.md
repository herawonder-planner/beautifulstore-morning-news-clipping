# news-clip-one: 기사 원문 1건 요약

기사 1건의 원문을 확인하고, 줄마다 원문 근거가 붙은 3줄 요약을 파일로 저장한다. 이 스킬은 요약 파일을 만드는 데까지만 하며 발송·공유는 하지 않는다.

## 입력
- 기사 URL 1개, 또는 `samples/` 안의 가상 기사 파일 경로 1개. 선택으로 기준일.
- 여러 개가 들어오면 첫 1건만 처리하고, 나머지는 처리하지 않았다고 사용자에게 알린다.
- 입력이 없거나 `http(s)://` 주소·`samples/` 파일 경로가 아니면 파일을 만들지 않고 기사 주소 1개를 다시 요청한다.
- `samples/` 파일이 존재하지 않으면 파일을 만들지 않고 경로를 다시 확인해 달라고 알린다(가상 기사를 대신 만들지 않는다).
- URL 입력인데 내장 브라우저 도구가 없으면(예: 일반 터미널 `claude`) curl 등으로 대체하지 않고, 파일 없이 "데스크톱 앱 Code 탭에서 실행해 주세요"라고 알린다.

## 준비
- 실행일은 서울 시간(KST) 기준 오늘 날짜(YYYY-MM-DD)다.
- 출력 폴더는 `output/<YYYY-MM-DD>/`. 없으면 만든다.
- 번호 NN은 그 폴더에 이미 있는 `summary-NN.md` 다음 번호(없으면 01)다. 기존 파일은 덮어쓰지 않는다.
- 결과 형식은 `templates/summary.md`를 따른다.

## 1. 원문 읽기
- URL 입력: 내장 브라우저(`mcp__Claude_Browser__preview_start` 또는 `navigate`, 이어서 `get_page_text`)로 연다. 제목·발행일이 본문 텍스트에 없으면 `javascript_tool`로 메타(`og:title`, `article:published_time` 등)를 읽는다.
- 로그인, 결제, 쿠키 동의는 하지 않는다. 비필수 쿠키 거부만 허용한다.
- 파일 입력(`samples/`): Read로 직접 읽는다. 데이터 구분은 "가상 예시"이고 제목 앞에 `[가상 예시]`를 붙인다.
- 확인 항목: 제목, 언론사, 발행일(KST로 변환. 원문 표기가 다르면 괄호로 병기 가능), 최종 URL, 본문.
- 페이지를 연 직후에는 `location.href`가 입력 주소와 같은지(또는 리다이렉트로 바뀌었는지) 확인하고 로딩이 끝난 뒤 읽는다. 최종 URL이 입력과 다르면 보고할 때 두 주소를 함께 알린다.

## 2. 접근 실패 판정
아래 중 하나라도 해당하면 요약을 만들지 않고 실패 파일만 쓴다.
- 페이지 열기 오류 또는 404
- 로그인·유료 벽
- 본문이 200자 미만
- 본문에 '아름다운가게'가 없음(관련 없는 기사)

실패 파일은 `templates/summary.md`의 실패 형식으로 `output/<날짜>/summary-NN.md`에 쓴다. `source-NN.txt`는 저장하지 않는다.

## 3. 본문 저장 (성공 시)
`output/<날짜>/source-NN.txt`에 저장한다.
```
# 원문 본문 (내부 대조용 · 외부 공유 금지)
URL: <최종 URL>

<본문 텍스트>
```

## 4. 요약
- 광고, 관련기사, 기자 소개 등 본문 외 텍스트는 제외한다.
- 정확히 3줄. 각 줄은 원문에 있는 사실만 쓴다. 추측·평가·원문에 없는 숫자를 넣지 않는다.
- 각 줄 바로 아래에 `   > 근거: "…"` 를 붙인다. 근거는 `source-NN.txt` 본문에서 글자 그대로 복사한 한 문장(또는 문장 일부, 20자 이상)이다. 다시 쓰거나 줄이지 않는다.
- 요약의 숫자·이름·날짜는 근거 문장과 일치해야 한다.
- `output/<날짜>/summary-NN.md`로 저장한다.

## 5. 자동 검사
저장 후 반드시 실행한다.
```
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-summary.ps1 -Summary output/<날짜>/summary-NN.md
```
`[FAIL]`이 있으면 summary를 고치고 다시 검사한다. 모두 통과할 때까지 반복한다.

## 6. 대화로 보고
- 파일 위치(summary, source)
- 제목, 발행일, URL
- 3줄 요약
- 검사 결과(통과/실패 수)

발송하거나 어디에도 공유하지 않는다. 담당자가 원문과 대조해 확인한다.
